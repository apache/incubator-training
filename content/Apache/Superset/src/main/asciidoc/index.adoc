== What is Apache Superset?

A modern, enterprise-ready BI web application.

* **Fast** — Optimized for large-scale data
* **Intuitive** — No-code chart builder for analysts
* **Powerful** — Full SQL IDE for data engineers
* **Extensible** — Plugin architecture for custom viz

[.notes]
--
Created at Airbnb in 2015 by Maxime Beauchemin (who also created
Apache Airflow). Graduated to Apache TLP in January 2021.
--

== Project History

* **2015** — Created at Airbnb by Maxime Beauchemin
* **2017** — Entered the Apache Incubator
* **2021** — Graduated to Apache Top-Level Project
* **Community** — 39 PMC members, 1,700+ contributors

[.notes]
--
Superset has grown from an internal Airbnb tool to one of the most
popular open source BI platforms, with millions of Docker pulls.
--

== Why Superset?

* **Free** — No license fees, open source
* **Open** — SQL standards, 40+ database connectors
* **Cloud-native** — Browser-based, deploy in minutes
* **Flexible** — From simple charts to complex dashboards

[.notes]
--
Compared to traditional BI (Tableau, Power BI, Looker): Superset is
free, uses open standards, and deploys in minutes with Docker.
--

== Key Features

* **No-Code Chart Builder** — 40+ chart types, drag-and-drop
* **SQL Lab** — Full SQL IDE with autocomplete
* **Semantic Layer** — Define metrics once, reuse everywhere
* **Interactive Dashboards** — Cross-filtering and drill-down
* **RBAC** — Row/column-level security

[.notes]
--
The extensible plugin system lets you build custom React visualizations.
--

== Supported Databases

Connects to any SQL-speaking database via SQLAlchemy:

* PostgreSQL, MySQL, SQLite, SQL Server, Oracle
* BigQuery, Redshift, Snowflake, Databricks
* Hive, Druid, Pinot, Trino/Presto, ClickHouse
* **30+ more** via community connectors

[.notes]
--
Superset never copies your data — it queries sources directly.
--

== Architecture

* **Frontend** — React single-page app
* **Backend** — Flask + SQLAlchemy (Python)
* **Metadata DB** — PostgreSQL (stores dashboards/users)
* **Cache** — Redis (optional, for performance)
* **Async** — Celery workers for long queries

[.notes]
--
The frontend communicates via REST APIs. SQLAlchemy provides the
universal database abstraction layer. See docs for full diagram.
--

== Chart Types

40+ visualization types out of the box:

* **Basic** — Bar, Line, Area, Pie, Scatter
* **Time Series** — Trend lines, mixed charts
* **Geographic** — Deck.gl, Choropleth, GeoJSON
* **Advanced** — Pivot, Sankey, Treemap, Funnel

[.notes]
--
All chart types are plugins. Organizations can add custom
visualization types using React and D3.js.
--

Used by Airbnb, American Express, Dropbox, Lyft, Netflix, and more.

== Installation Methods

* **Docker Compose** — Quickstart, demos (easy)
* **pip install** — Production, customization (medium)
* **From Source** — Development, contributing (advanced)

[.notes]
--
Docker Compose is recommended for getting started.
pip install with proper config for production.
--

== Prerequisites

* Python 3.9+
* PostgreSQL (for metadata store)
* 4GB+ RAM (8GB recommended)
* Linux or macOS (Windows via WSL2/Docker)

== Install with Docker

[source,bash]
----
git clone https://github.com/apache/superset.git
cd superset
docker compose -f docker-compose-image-tag.yml up -d
----

Access at: http://localhost:8088

[.notes]
--
Includes Redis, PostgreSQL metadata DB, and Celery worker.
--

== Install with pip

[source,bash]
----
pip install apache-superset
export SUPERSET_SECRET_KEY='your-secret-key'
superset db upgrade
superset fab create-admin
superset init
superset run -p 8088
----

[.notes]
--
In production, use Gunicorn and configure PostgreSQL as the metadata DB.
--

== Install from Source

[source,bash]
----
git clone https://github.com/apache/superset.git
cd superset
pip install -e .
cd superset-frontend && npm ci && npm run build
cd .. && superset db upgrade && superset init
superset run -p 8088
----

[.notes]
--
Required for contributing code or building custom frontend plugins.
--

== Configuration

Key settings in `superset_config.py`:

[source,python]
----
SECRET_KEY = 'generate-with-openssl-rand'
SQLALCHEMY_DATABASE_URI = 'postgresql://...'
CACHE_CONFIG = {'CACHE_TYPE': 'RedisCache'}
FEATURE_FLAGS = {'DASHBOARD_CROSS_FILTERS': True}
----

Set `SUPERSET_CONFIG_PATH` env var to your config file.

== Connect a Database

. Go to **Settings → Database Connections**
. Click **+ Database**
. Select type, enter SQLAlchemy URI
. Click **Test Connection** → **Connect**

[.notes]
--
Superset never copies data — it queries sources directly.
--

== Create a Dataset

. Navigate to **Datasets → + Dataset**
. Select database, schema, and table
. Click **Create Dataset and Create Chart**

A dataset stores column metadata and metric definitions.

== Build a Chart

. Select visualization type (e.g., Bar Chart)
. Drag columns to **Dimensions**
. Drag metrics to **Metrics**
. Click **Create Chart** → **Save**
