== How to Contribute

=== The Apache Way (quick overview)

* Community over code
* Earned authority (meritocracy)
* Lazy consensus
* Open development — all discussion on public mailing lists

=== Contribution Workflow

. *Find an issue* — browse "good first issue" labels or ask on dev@
. *Discuss your approach* — email the dev list or comment on the issue
. *Fork and branch* — `git checkout -b my-feature`
. *Make your change* — follow the project's coding standards
. *Test* — run the project's test suite
. *Submit a PR* — reference the issue number
. *Respond to review* — iterate based on feedback
. *Celebrate* 🎉 — your contribution is merged!

== Beyond Code

// Not all contributions require writing code.

* *Documentation* — fix typos, improve guides, translate
* *Testing* — reproduce bugs, write test cases
* *Triage* — help categorize and prioritize issues
* *User support* — answer questions on the user@ list
* *Evangelism* — write blog posts, give talks, create tutorials
