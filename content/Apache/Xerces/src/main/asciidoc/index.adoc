== Apache Xerces

image::project-logo.png[Apache Xerces, 500]

XML Parsers in Java, C++ and Perl

[.notes]
--
Welcome to this introduction to Apache Xerces. The Xerces project provides
high-performance, standards-compliant XML parsers in multiple programming
languages. It has been a top-level Apache project since 2005 and traces its
origins to 1999.
--

== The Apache Xerces Project

* Responsible for creation and maintenance of XML parsers
* Provides parsing, validating, serializing and manipulating XML
* Implementations in Java, C++ and Perl
* Top-level Apache project since February 2005

[.notes]
--
The Apache Xerces Project is responsible for software intended for the
creation and maintenance of XML parsers. It became a top-level project
at the ASF in February 2005, after starting as part of the Apache XML
project. The project originated from code donations in 1999.
--

== Sub-Projects

[cols="1,3"]
|===
| Sub-Project | Description

| Xerces2 Java
| Parsing, validating and manipulating XML in Java

| Xerces-C++
| Parsing, validating, serializing and manipulating XML in C++

| Xerces Perl
| Perl API to the Xerces C++ parser (XML::Xerces)

| XML Commons
| Collection of XML components including a catalog resolver
|===

[.notes]
--
Xerces consists of four sub-projects. Xerces2 Java and Xerces-C++ are
the primary active components. Xerces Perl provides Perl bindings to
the C++ parser. XML Commons provides shared utilities including an
OASIS XML Catalog resolver used by many Apache projects.
--

== Xerces2 Java — Overview

* High-performance, fully compliant XML parser
* Built on the Xerces Native Interface (XNI) framework
* XNI is modular and easy to extend
* Current release: *2.12.2*
* Supports XML 1.0 (4th Ed.) and XML 1.1 (2nd Ed.)

[.notes]
--
Xerces2 Java is the flagship sub-project. It introduced the Xerces Native
Interface, a complete framework for building parser components and
configurations. Application developers use standard APIs like JAXP, DOM
and SAX — XNI is the internal framework for those who need more power
and flexibility.
--

== Xerces2 Java — Standards Support

* XML Schema 1.0 (2nd Ed.) and XML Schema 1.1
* DOM Level 3 Core, Load and Save
* DOM Level 2 Core, Events, Traversal and Range
* SAX 2.0.2 Core and Extensions
* JAXP 1.4 and StAX 1.0 Event API
* XInclude 1.0 (2nd Ed.) and OASIS XML Catalogs 1.1

[.notes]
--
Xerces2 Java provides extensive standards support. It is one of the few
parsers offering both XML Schema 1.0 and 1.1 support. The DOM Level 3
implementation covers Core and Load/Save. It also supports XInclude and
OASIS XML Catalogs for entity resolution.
--

== Xerces-C++ — Overview

* Validating XML parser written in portable C++
* Current release: *3.3.0* (source-only distribution)
* Supports DOM, SAX and SAX2 APIs
* XML 1.0 (3rd Ed.), XML 1.1, W3C XML Schema, DOM Level 3
* Minimal use of templates, no RTTI, minimal #ifdefs

[.notes]
--
Xerces-C++ provides a shared library for parsing, generating,
manipulating and validating XML documents. It emphasizes portability.
Note that the project currently notes it lacks active maintainers.
It supports DOM Level 3, XML Schema, XInclude, Namespaces, and
Element Traversal among other standards.
--

SAX 2.0.2, JAXP 1.4 interfaces).

== Java: Parsing with JAXP

[source,java]
----
import javax.xml.parsers.*;
import org.w3c.dom.*;

DocumentBuilderFactory factory =
    DocumentBuilderFactory.newInstance();
factory.setNamespaceAware(true);
factory.setValidating(true);

DocumentBuilder builder = factory.newDocumentBuilder();
Document doc = builder.parse("catalog.xml");
----

[.notes]
--
The simplest way to use Xerces2 Java is through the JAXP API. This
example creates a namespace-aware, validating parser and parses an
XML document into a DOM tree. JAXP provides portability — you can
swap parser implementations without changing code.
--

== Java: SAX Parsing

[source,java]
----
import javax.xml.parsers.*;
import org.xml.sax.helpers.DefaultHandler;

SAXParserFactory factory =
    SAXParserFactory.newInstance();
factory.setNamespaceAware(true);

SAXParser parser = factory.newSAXParser();
parser.parse("catalog.xml", new DefaultHandler() {
    // Override callback methods here
});
----

[.notes]
--
SAX parsing is event-driven and memory-efficient for large documents.
You extend DefaultHandler and override callback methods like
startElement, endElement and characters. Xerces2 supports SAX 2.0.2
Core and Extensions.
--

== C++: Basic Initialization

[source,cpp]
----
#include <xercesc/util/PlatformUtils.hpp>
using namespace xercesc;

int main(int argc, char* argv[]) {
    try {
        XMLPlatformUtils::Initialize();
    } catch (const XMLException& e) {
        return 1;
    }
    // Work with Xerces-C++ here
    XMLPlatformUtils::Terminate();
    return 0;
}
----

[.notes]
--
Every application using Xerces-C++ must call Initialize before using
any API and Terminate when done. These must be called at least once
per process. You can call them multiple times, but each Initialize
must be matched with a Terminate call.
--

== C++: DOM Parsing

[source,cpp]
----
#include <xercesc/parsers/XercesDOMParser.hpp>
#include <xercesc/dom/DOM.hpp>
using namespace xercesc;

XercesDOMParser* parser = new XercesDOMParser();
parser->setValidationScheme(
    XercesDOMParser::Val_Always);
parser->parse("catalog.xml");
DOMDocument* doc = parser->getDocument();
// Traverse the DOM tree
delete parser;
----

[.notes]
--
This shows basic DOM parsing with Xerces-C++. You create a parser,
configure validation, parse the document, then work with the resulting
DOM tree. The parser provides high performance and modularity, with
support for pluggable validators and encodings.
--

== C++: SAX2 Parsing

[source,cpp]
----
#include <xercesc/sax2/SAX2XMLReader.hpp>
#include <xercesc/sax2/XMLReaderFactory.hpp>
using namespace xercesc;

SAX2XMLReader* reader =
    XMLReaderFactory::createXMLReader();
reader->setFeature(
    XMLUni::fgSAX2CoreValidation, true);
reader->setContentHandler(myHandler);
reader->parse("catalog.xml");
delete reader;
----

[.notes]
--
SAX2 parsing in Xerces-C++ uses the XMLReaderFactory to create a
reader, then configures features and sets your custom content handler.
This is the preferred SAX API — SAX1 is also available but SAX2 is
recommended for new applications.
--

== XML Schema Validation (Java)

[source,java]
----
import javax.xml.validation.*;
import javax.xml.transform.stream.StreamSource;

SchemaFactory sf = SchemaFactory.newInstance(
    "http://www.w3.org/2001/XMLSchema");
Schema schema = sf.newSchema(
    new StreamSource("schema.xsd"));
Validator validator = schema.newValidator();
validator.validate(new StreamSource("doc.xml"));
----

[.notes]
--
Xerces2 Java provides the reference implementation for XML Schema
validation through JAXP. This shows standalone schema validation using
the javax.xml.validation API. Xerces supports both XML Schema 1.0 and
1.1 — Schema 1.1 is available in the separate distribution package.
--
